# Budgeting and rolling forecast

## What this process covers
### Purpose
- Set targets the business can deliver
- Update the outlook as the year moves
### In scope
- Annual budget by store, category, cost centre
- Quarterly rolling forecast and scenarios
### Outcome
- An approved budget loaded for reporting
- A forecast leaders trust

## FP&A runs the cycle, the business owns the numbers
Layout: swimlane handoffs
- FP&A: Sets the targets and drivers
- Store and category leads: Submit their plans
- FP&A: Consolidates the plans
- FP&A: Plan meets the target?
- FP&A: If yes, submit for approval
- Business leads: If no, revise the plan
- Executive team: Approves the budget

## The systems and data it runs on
| Step | What the system does | Records it keeps |
|---|---|---|
| Planning model | One model for budget and forecast | Planning model, versions |
| Actuals | Actuals loaded from the ledger | Actual results |
| Plan data | The approved plan loaded for reporting | Plan version |
| Drivers | Stores, traffic, conversion, basket | Driver tables |
| Reporting | Plan vs actual by owner | Variance reports |

## The planning cycle repeats every quarter
Layout: process cycle
- Target: top-down frame
- Plan: bottom-up by owner
- Consolidate: one version
- Approve: executive sign-off
- Track: plan vs actual
- Re-forecast: each quarter

## Controls and exceptions
| Control | How it works | Owner |
|---|---|---|
| Version control | One approved version per cycle | FP&A |
| Driver sign-off | Key drivers agreed before planning | FP&A lead |
| Submission deadlines | Late submissions escalate | FP&A |
| Approval trail | Every change after approval recorded | FP&A |

## KPIs that show it works
| KPI | What it measures | Data source |
|---|---|---|
| Forecast accuracy | Forecast vs actual for the quarter | Plan vs actual |
| Planning cycle time | Days to complete the budget | Planning calendar |
| Plan adherence | Spend within the approved budget | Actual vs plan |
| Scenario turnaround | Hours to model a new scenario | Planning log |
