# Capital request and tracking

## What capital request and tracking covers
### Purpose
- Spend capital where the return is best
- Keep every project inside its approval
### In scope
- New stores, remodels, DCs and technology
- Requests, approval, spend, assets, lookbacks
### Outcome
- Projects approved against clear returns
- Assets capitalized and depreciated on time

## Sponsors propose, the committee decides
Layout: swimlane handoffs
- Project sponsor: Submits the request and business case
- FP&A: Reviews returns and fit with the plan
- Capital committee: Return clears the hurdle rate?
- Capital committee: If yes, approve the budget
- Project sponsor: If no, rework or withdraw it
- Fixed asset accounting: Capitalizes when in service

## Systems and data for capital projects
| Step | What the system does | Records it keeps |
|---|---|---|
| Capital plan | Yearly envelope by program | Capital plan version |
| Request | Business case and approvals routed | Capital request |
| Project | Budget and cost collector opened | Project budget |
| Spend | Commitments and actuals by project | Purchase orders, actuals |
| Capitalize | Assets created when in service | Fixed asset records |

## Six steps from idea to lookback
Layout: process numbered
- Plan: the capital envelope for the year
- Request: business case, returns and risks
- Approve: by delegation of authority
- Track: commitments and spend against budget
- Capitalize: when the asset is in service
- Look back: actual return against the case
> Notes: a business case shows the investment, net present value, internal rate of return and payback; the lookback compares them with actuals after [n] months.

## Controls keep projects inside approval
| Control | How it works | Owner |
|---|---|---|
| Approval by authority | Approval level set by project value | CFO office |
| Overrun approval | Spend over budget by [n]% needs a new approval | Capital committee |
| Capitalization review | Only qualifying costs are capitalized | Fixed asset accounting |
| Work in progress review | Projects in service but not capitalized flagged | Asset accounting lead |

## KPIs show spend and returns
| KPI | What it measures | Data source |
|---|---|---|
| Spend vs budget | Actual and committed vs approved | Project budgets |
| Return vs case | Actual return vs the approved case | Lookback reviews |
| Days to approve | Request to approval | Workflow dates |
| Capitalization lag | Days from in service to capitalized | Asset records |

## From slide decks to one request flow
### Today
- Requests in slide decks and e-mail
- Few projects ever looked back on
### Target
- One request flow with returns and approvals
- A lookback for every major project
