# Fit-to-standard workshops

## What fit-to-standard covers
### Purpose
- Start from the standard process, not a blank page
- Agree fit, gap or change for every step
### In scope
- Each end-to-end process in the release
- Process owners, key users, solution leads
### Outcome
- A signed-off fit-gap list and backlog
- Few gaps, each one justified

## Fit-to-standard in four phases
Layout: process phases
- Prepare: scope; demo data; pre-reads (Weeks 1-2)
- Show: standard demos; walk-throughs (Weeks 3-6)
- Decide: fit; gap; process change (Weeks 5-7)
- Sign off: backlog; design baseline (Week 8)
> Notes: example durations for one release - plan one workshop series per end-to-end process.

## How one workshop runs
Layout: process numbered
- Show: the standard process with our sample data
- Walk: our steps against the standard
- Mark: fit, gap or process change per step
- Rank: must, should or could for each gap
- Log: decisions and owners the same day

## Who is in the room
| Role | Brings | Accountable for |
|---|---|---|
| Workshop lead | Standard process demo and options | An accurate fit-gap list |
| Process owner | The business view and the final say | Fit, gap or change decisions |
| Key users | How the work is done today | Real scenarios and test cases |
| Solution architect | Integration and extension options | Input to the design authority |
| Change lead | Who is affected and how | Impact notes for each change |

## Every gap has a way to close it
| Option | When we use it | Approves |
|---|---|---|
| Change the process | The standard works if we work differently | Process owner |
| Configure | Settings, rules or workflow meet the need | Workshop lead |
| Extend | It sets us apart and no setting covers it | Design authority |
| Report or interface | The need sits outside the solution | Solution architect |
| Work around | Rare, low volume, no business case | Steering committee |

## How a gap is approved
Layout: swimlane handoffs
- Workshop lead: Logs the gap with the business reason
- Process owner: Can we change the process?
- Process owner: If yes, adopts the standard way
- Design authority: If no, reviews options and effort
- Steering committee: Approves extensions over tolerance
- Workshop lead: Updates the backlog and the design

## Signed off when
| Criterion | Target | Evidence |
|---|---|---|
| Workshops held | All in scope | Workshop tracker |
| Steps decided | 100% fit, gap or change | Fit-gap list |
| Gaps owned and ranked | 100% | Backlog report |
| Extensions approved | Each one by the design authority | Decision log |
