# Phase-gate plan

## Phases and gates
Layout: process phases
- Discover: problem; options (Gate 1)
- Define: scope; business case (Gate 2)
- Develop: build; test (Gate 3)
- Deploy: launch; adopt (Gate 4)
- Deliver value: benefits (Close)

## The gates on the timeline
Layout: timeline template-milestones
- Gate 1 - Idea approved: Feb 15, 2027 (Portfolio board)
- Gate 2 - Case approved: Apr 30, 2027 (Investment committee)
- Gate 3 - Ready to launch: Sep 30, 2027 (Steering committee)
- Gate 4 - Close: Jan 31, 2028 (Portfolio board)

## What each gate checks
| Gate | Question | Evidence | Decides |
|---|---|---|---|
| Gate 1 | Is the problem worth solving? | Problem statement, sizing | Portfolio board |
| Gate 2 | Is the case strong enough to fund? | Business case, plan, risks | Investment committee |
| Gate 3 | Is it ready to launch? | Test results, readiness | Steering committee |
| Gate 4 | Did we deliver the value? | Benefits, lessons | Portfolio board |

## How a gate decision is made
Layout: swimlane handoffs
- Project lead: Submits the gate pack early
- Gate reviewers: Check evidence against criteria
- Gate board: Criteria met?
- Gate board: If yes, go to the next phase
- Project lead: If no, closes gaps or stops work
