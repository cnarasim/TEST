# Programme review timeline

## How the programme ran
Layout: timeline lanes
- Design: Jan 2027 – Apr 2027 (Business)
- Build: Apr 2027 – Aug 2027 (Technology)
- Test: Jul 2027 – Oct 2027 (Business)
- Deploy: Oct 2027 – Dec 2027 (Project)
- Go-live: Nov 9, 2027 (Project)

## Events that shaped it
Layout: process list
- Scope reset: Mar 15, 2027 (two features moved to phase 2)
- Supplier change: Jun 1, 2027 (new integration partner)
- Freeze moved: Sep 1, 2027 (go-live pulled forward)

## What worked and what did not
### Worked
- Early business ownership of design
- Three data trial loads
### Did not work
- Late start on interfaces
- Testers hired late
### Next time
- Riskiest build first
- Staff testing at design sign-off

## Lessons on the timeline
| When | What happened | Lesson |
|---|---|---|
| Design | Scope too wide | Agree what is out early |
| Build | Interfaces late | Start the riskiest build first |
| Test | Testers late | Staff testing at design sign-off |
| Deploy | Clean cutover | Keep three trial loads |
