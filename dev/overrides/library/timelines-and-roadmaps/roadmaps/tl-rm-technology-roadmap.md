# Technology roadmap

## Platforms by lane
Layout: gantt
- Commerce platform upgrade: Jan 2027 – Jun 2027 (Digital)
- Order management consolidation: Apr 2027 – Dec 2027 (Digital)
- Store systems refresh: Mar 2027 – Nov 2027 (Stores)
- Warehouse system upgrade: Jul 2027 – Mar 2028 (Supply chain)
- Data platform: Jan 2027 – Sep 2027 (Data)
- Legacy order system retired: Jan 31, 2028 (Digital)
> Notes: example dates; "(Lane)" names the swim lane, a single date is a milestone.

## Retirements and why they matter
Layout: process list
- On-premise reporting: retired Jun 30, 2027 (moves to the data platform)
- Old store handhelds: retired Nov 30, 2027 (new devices with the refresh)
- Legacy order system: retired Jan 31, 2028 (saves run cost, one order view)

## Dependencies between the moves
Layout: process converge
- Data platform: single source for products and stock
- Order consolidation: one place for every order
- Store refresh: new devices and network
- Result: One view of stock and orders - ready for same-day promises
